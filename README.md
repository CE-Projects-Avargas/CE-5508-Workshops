# CE5508 - Talleres

Repositorio de talleres prácticos del curso CE5508 (Arquitectura Orientada a Servicios aplicada a Sistemas Emergentes), Tecnológico de Costa Rica.

Cada carpeta es un taller independiente: trae su propio `README.md` con instrucciones, una base de código funcional (o parcialmente funcional, con TODOs) y, cuando aplica, un `docker-compose.yml` para levantar todo con un solo comando.

## Talleres

| Carpeta | Tema |
|---|---|
| [`01-docker-login`](01-docker-login/) | Docker + Docker Compose, API REST con Node/Express/Sequelize, servicio de autenticación en Python/Flask, MariaDB, sesiones con JWT |

## Cómo usar este repositorio

```bash
git clone git@github.com:CE-Projects-Avargas/CE-5508-Workshops.git
cd CE-5508-Workshops/<carpeta-del-taller>
```

Luego sigue el `README.md` de esa carpeta.
